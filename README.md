# Bellu Grave Finder

Mobile-first search for notable graves in Cimitirul Bellu (Bucharest), with an interactive
map of the cemetery plan. Data is transcribed from the entrance information board
("Planul Cimitirului Bellu" — *Personalități din lumea culturală, științifică și militară*).

- Diacritic-insensitive, multi-term search across figura, name, role and years
  (`eminescu`, `actor 96`, `caragiu`). A bare number searches by figura (`96`).
- Tap a result to fly to its plot on the plan; tap a plot marker to list everyone buried there.
- Searches are kept in the URL (`#q=Eminescu`) so results can be shared.
- Installable PWA that works offline (handy in the cemetery, where signal is poor): add it to
  the home screen from the browser menu after the first visit.

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # typecheck + production build into dist/
```

Stack: TypeScript, [Vite](https://vite.dev), [Leaflet](https://leafletjs.com) (`CRS.Simple` over the plan image),
[vite-plugin-pwa](https://vite-pwa-org.netlify.app) (manifest + Workbox service worker).
The service worker is only generated by `npm run build`; test offline behaviour with `npm run preview`.

## Deployment

`.github/workflows/deploy.yml` builds on every PR and deploys `main` to GitHub Pages.
One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Data

| File | What |
| --- | --- |
| `src/data/graves.ts` | `RAW`: one line per grave, `figura\|name\|years\|role`; `NOTES` for extra hints |
| `src/data/plots.ts` | pixel position of each figura label on `src/assets/plan.jpg` |
| `src/assets/plan.jpg` | greyscale crop of the plan from `photos/board-full-plan.jpg` |
| `photos/` | original photos of the boards — the source of truth for the data |

To place a new figura on the map, open `src/assets/plan.jpg` (1910×870), find the label's
pixel position and add it to `PLOTS`. Figs 74 and 75 bis are listed on the board but not
drawn on the plan, so they have no marker.
